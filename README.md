# CueSports App

CueSports is a complete management and customer app for billiards, snooker, and pool centers. It
helps players find, book, and manage tables, while enabling owners to handle operations, payments,
and analytics in one place.

---

## Overview

CueSports connects players and cue sports venues through a modern digital platform.
It simplifies table booking, live availability tracking, billing, and customer management for both
users and venue owners.

---

## Features

### For Players

* User registration and login
* Search nearby snooker/pool centers
* View live table availability
* Book tables in advance
* Extend playing time
* Online payments
* Booking history
* Notifications for booking status

---

### For Venue Owners

* Dashboard to manage tables
* Real-time table status (Available / Occupied / Reserved)
* Walk-in and online booking management
* Automatic billing based on play time
* Payment tracking (Cash / Online)
* Customer management
* Daily, weekly, and monthly reports
* Revenue analytics

## How It Works

1. User opens the app and logs in.
2. Selects a nearby cue sports center.
3. Checks table availability.
4. Books a table or walks in.
5. Owner manages session and billing.
6. Payment is completed and stored.
7. Reports are generated automatically.
